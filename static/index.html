项目部署

启动服务并连接 iOS App。

读取监听配置中
1

启动服务

首次部署将 .env.example 复制为 .env，填写 DEEPSEEK_API_KEY。 

uv sync --locked
uv run python -m relax_ai_lab --host 0.0.0.0 --port 8765

其他启动方式 
./scripts/dev.sh --host 0.0.0.0

也可通过 .env 的 LAB_HOST、LAB_PORT 配置监听地址与端口。

2

选择连接地址

选择手机所在网络的 Wi-Fi 或以太网地址。

健康检查

用手机浏览器打开，返回 status: ok 即可继续。

3

配置 iOS

Xcode → Edit Scheme → Run → Arguments → Environment Variables

使用 Relax / Local Debug，重新 Run 启动 App。

连接排查
  • 手机和部署电脑连接同一局域网，检查防火墙端口与 Wi-Fi 客户端隔离。
  • 真机填写电脑的局域网 IP；同机模拟器可使用 localhost。
  • App 首次请求时允许“本地网络”权限；已拒绝时可在系统设置中开启。
