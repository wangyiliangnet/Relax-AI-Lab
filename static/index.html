读取监听配置中
1

启动服务

首次部署将 .env.example 复制为 .env，填写 DEEPSEEK_API_KEY。 

uv sync --locked
uv run python -m relax_ai_lab --host 0.0.0.0 --port 8765

其他启动方式 
./scripts/dev.sh --host 0.0.0.0

也可通过 .env 的 LAB_HOST、LAB_PORT 配置监听地址与端口。

2

选择连接地址

选择手机所在网络的 Wi-Fi 或以太网地址。

健康检查

用手机浏览器打开，返回 status: ok 即可继续。

3

配置 iOS

Xcode → Edit Scheme → Run → Arguments → Environment Variables

使用 Relax / Local Debug，重新 Run 启动 App。

共享模拟权益

Web 单目标模拟与 iOS 共用此账本；固定用例使用各自的模拟权益。

仅修改模拟权益，不改变生成配置。模拟积分与人民币 token 费用分别管理。

连接排查
  • 手机和部署电脑连接同一局域网，检查防火墙端口与 Wi-Fi 客户端隔离。
  • 真机填写电脑的局域网 IP；同机模拟器可使用 localhost。
  • App 首次请求时允许“本地网络”权限；已拒绝时可在系统设置中开启。

DeepSeek 官方价格 ↗

内置 DeepSeek 高峰期、DeepSeek 空闲时段、全时段三种单价版本。Flash 和 Pro 已内置官方高峰/空闲价格（2026-11-07 核对），按调用开始的北京时间及中国节假日日历自动选择。单位为元 / 百万 tokens。

内置及自定义价格均可删除，刷新或重启后保持删除。删除仅影响后续调用，历史费用快照保留；无其他匹配价格时费用为未知。可在下方重新填写并保存价格。

全时段价格适用于每天 00:00–24:00，需要自行填写；同模型优先使用自定义时段价格，其次是全时段价格，再使用内置价格。高峰为北京时间周一至周五（中国法定节假日除外）09:00–12:00、14:00–18:00，其余为空闲时段，周末补班仍按空闲计。日历暂覆盖 2004–2027 年，超出范围的工作日高峰窗口保留未知。

已有 DeepSeek 调用已按记录时间和内置价格重新估算，详情保留原费用与价格快照。以后调价仅影响后续调用。无匹配价格或缺少用量时为未知；Mock 和明确未发送的请求为零。最终扣费以 Provider 账单为准。
